Halaman Error LMS Bengkel Koding

Daftar implementasi halaman error 100% konsisten dengan komponen PageNotFound.tsx dan PageUnauth.tsx dari lms-bengkod-web.

404 PageNotFound.tsx

Upss, halaman tidak ditemukan

Sesuai dengan app/not-found.tsx pada LMS Bengkel Koding.

403 PageUnauth.tsx

Upss, Mau kemana?

Sesuai dengan features/shared/components/PageUnauth.tsx.

500 Internal Server Error

Upss, terjadi kesalahan server

Penanganan kendala sistem dengan tombol muat ulang halaman.

503 Service Unavailable

Upss, sedang ada pemeliharaan

Penanganan pemeliharaan sistem berkala dengan tombol cek status.
